# Investigación técnica aplicada

Esta sección convierte experiencias de evaluación e ingeniería en estudios públicos breves. Se conservan el problema, los criterios, el razonamiento y las decisiones técnicas; se excluyen cotizaciones, contactos, identificadores, planos internos y datos operativos de terceros.

| [Selección de motores para invernadero](03-seleccion-motores-invernadero.md) | Requisitos mecánicos y eléctricos, inventario y descarte trazable |

| [Método para comparativas técnicas](07-metodologia-comparativas.md) | Proceso reproducible para pasar de requisitos a recomendación |

## Cómo leer los casos

Cada resumen diferencia entre evidencia disponible, decisión y límites. Cuando el informe original no puede publicarse, el caso se presenta como síntesis metodológica y no como reproducción del documento laboral. Las cifras incluidas son únicamente requisitos generales o resultados ya anonimizados.
