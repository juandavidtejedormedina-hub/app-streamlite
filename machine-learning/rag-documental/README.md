# RAG documental con modelos locales

Proyecto académico de recuperación aumentada con generación sobre un PDF del Código Nacional de Tránsito de Colombia. Combina extracción por páginas con PyMuPDF, embeddings y búsqueda de fragmentos, seguida de generación con modelos locales mediante Ollama.

[Abrir el repositorio completo: Proyecto-RAG](https://github.com/juandavidtejedormedina-hub/Proyecto-RAG)

El repositorio contiene `RAG.PY`, instrucciones, dependencias, configuración de ejemplo y el documento utilizado. Los modelos configurados en esa entrega son `all-minilm` para embeddings y `llama3.2:3b` para generación. Mantener el proyecto en su repositorio original conserva sus documentos y su historial.

**Qué revisar:** la preparación del PDF, la estrategia de fragmentación, la recuperación del contexto y el manejo de respuestas. Es una demostración técnica sobre documentos; no acredita actualización normativa ni precisión jurídica. No se ejecutaron nuevamente los modelos de Ollama al organizar este portafolio.
