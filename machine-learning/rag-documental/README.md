# RAG documental con modelos locales

Proyecto académico para consultar información dentro de un PDF usando recuperación de fragmentos y generación con modelos locales.

El flujo combina extracción de texto con PyMuPDF, embeddings para búsqueda semántica y generación mediante Ollama.

[Ver repositorio completo: Proyecto-RAG](https://github.com/juandavidtejedormedina-hub/Proyecto-RAG)

El proyecto utiliza `all-minilm` para embeddings y `llama3.2:3b` para generación. En el repositorio original están el código, las dependencias y el documento usado durante la práctica.

El objetivo fue trabajar el proceso completo: lectura del PDF, división del contenido, recuperación de contexto y generación de respuestas. Es un ejercicio técnico y no debe tomarse como fuente jurídica actualizada.
