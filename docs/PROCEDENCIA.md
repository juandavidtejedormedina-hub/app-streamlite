# Procedencia, autoría y edición

Este repositorio reúne archivos de proyectos recuperados y copias de código ya publicado en otros repositorios de Juan David Tejedor Medina. La organización y los ejemplos sintéticos se prepararon en septiembre de 2026.

## Trabajos académicos

El informe Bank Marketing está firmado por **Juan David Tejedor Medina y Miguel Gerardo Moreno Avendaño**, de la Especialización en Programación para Ciencia de Datos de la UPTC. Se conserva completo y sin cambios.

Los notebooks conservan sus encabezados de autoría. Algunos contienen variantes ortográficas del nombre del compañero; se mantienen tal como estaban en los archivos originales. El notebook Seq2Seq identifica al Grupo 3. Donde aparece material del curso y el docente Jersson, se mantiene esa atribución: las actividades desarrolladas no se presentan como autoría exclusiva de todo el material didáctico.

Se conservaron el código, las explicaciones y las conclusiones de los seis notebooks. Se añadieron identificadores de celda para el formato actual del notebook y se eliminaron salidas y metadatos de ejecución y se añadió una nota de edición. No se volvieron a entrenar los modelos de Deep Learning. Las conclusiones y métricas que permanezcan en el texto son las de la entrega original.

## Desarrollos aplicados

- **Temperatura:** notebook operativo adaptado para lectura local o Colab, con un conjunto sintético y validación de datos vacíos. Se retiraron referencias a métricas laborales no reproducidas.
- **Dashboards:** dos archivos Python recuperados. Se sustituyeron descargas corporativas por lectura local, se retiraron recursos de marca y ubicación, y se preparó un generador sintético nuevo. No se redistribuyen los Excel laborales.
- **Sensores:** tres codecs recuperados; solo se normalizaron nombres de archivo y saltos de línea. Los comentarios y reglas de decodificación se mantienen.
- **Reservorios y ACREL:** resúmenes públicos derivados de documentos técnicos. No se afirma que se haya recuperado el código completo de esas aplicaciones.
- **Power BI:** no se encontró un `.pbix` o `.pbit`. El documento recuperado bajo ese título corresponde a Streamlit.
