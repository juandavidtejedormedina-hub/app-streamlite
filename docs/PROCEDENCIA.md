# Notas sobre los proyectos

Este repositorio reúne proyectos académicos, desarrollos personales y versiones públicas de trabajos aplicados.

## Trabajos académicos

El informe de Bank Marketing fue realizado por **Juan David Tejedor Medina y Miguel Gerardo Moreno Avendaño** dentro de la Especialización en Programación para Ciencia de Datos de la UPTC.

Los notebooks conservan los nombres de integrantes y docentes cuando estaban incluidos en las entregas originales. También se mantienen las referencias al material de clase cuando corresponde.

Para reducir el tamaño de los archivos se retiraron salidas de ejecución de varios notebooks, pero se conservó el código y el contenido principal.

## Proyectos aplicados

Los proyectos relacionados con invernaderos, sensores e IoT fueron adaptados para publicación. No se incluyen bases de datos operativas, credenciales, identificadores de dispositivos, ubicaciones, cotizaciones ni información interna.

Cuando fue necesario, se agregaron datos sintéticos para permitir la ejecución del código sin exponer información real.
