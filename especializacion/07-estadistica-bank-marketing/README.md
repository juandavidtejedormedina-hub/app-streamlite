# Estadística y análisis exploratorio — Bank Marketing

Análisis de 45.211 registros y 17 variables del conjunto público Bank Marketing de UCI. El proyecto estudia la aceptación de depósitos a término mediante estadística descriptiva, visualizaciones, probabilidades condicionales y un modelo Beta-Binomial.

**Autores:** Juan David Tejedor Medina y Miguel Gerardo Moreno Avendaño.  
**Programa:** Especialización en Programación para Ciencia de Datos, UPTC.  
**Asignatura:** Estadística y Análisis Exploratorio de Datos.

[Leer el informe completo](informe-bank-marketing.pdf) · [Fuente del conjunto de datos](https://archive.ics.uci.edu/dataset/222/bank+marketing)

El informe presenta una tasa de aceptación de 11,70 % y un intervalo de credibilidad del 90 % de [11,45 %; 11,95 %]. Son resultados documentados en la entrega, sin recálculo durante esta publicación.

“DataVenture Analytics” y la consultoría descrita forman parte del escenario académico. El informe no representa experiencia laboral en una consultora ni asesoría a una entidad bancaria real. Se recuperó el PDF; no se encontró el código fuente en R para acompañarlo.
