# Desbalance de clases y regularización

Notebook académico enfocado en dos problemas comunes: clasificación con clases desbalanceadas y control del sobreajuste en regresión.

## Herramientas

Python, TensorFlow/Keras, NumPy, pandas, scikit-learn y Matplotlib.

## Datos

- Clasificación: conjunto sintético desbalanceado.
- Regresión: conjunto de diabetes de scikit-learn.

Se comparan métricas como F1 macro y balanced accuracy, y se prueban técnicas de regularización como L2 y Dropout.
