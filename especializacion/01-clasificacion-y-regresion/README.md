# Clasificación multiclase y regresión

Notebook académico con dos ejercicios: una red neuronal para clasificación multiclase y otra para regresión.

## Herramientas

Python, TensorFlow/Keras, NumPy, pandas, scikit-learn y Matplotlib.

## Datos

- Clasificación: datos sintéticos de cuatro clases.
- Regresión: conjunto de diabetes disponible en scikit-learn.

Durante el ejercicio se trabajó la preparación de datos, separación de entrenamiento y prueba, definición de la arquitectura y comparación de métricas y curvas de aprendizaje.
